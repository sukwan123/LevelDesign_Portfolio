## 수집 메모
- 같은 파일명이 여러 폴더에 중복 존재한다(백업본). 위 링크는 전부
  `# Level Design - <지역군>` 또는 해당 콘텐츠 정규 폴더의 원본이다.
- 던전 기획서는 `80 레벨&컨텐츠` 밖에 흩어져 있다 —
  크라켄은 `70 전투/몬스터`, 그리핀은 별도 던전 폴더, 하렌홀은 `40. Field Contents`.
- 검색은 Drive API `title = '<정확한 파일명>'` 를 `or` 로 묶는 게 가장 빠르다
  (`title contains` 는 페이지당 결과가 적어 페이징이 번거롭다).
