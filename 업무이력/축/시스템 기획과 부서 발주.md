# 시스템 기획과 부서 발주

← [[업무이력 허브]] · [[연표]]
**기간** 2022-08 ~ 2026-07 · **Jira 보고자 100건** · 직군 정체성을 규정하는 축

## 무엇을
레벨을 만들다 막히면, 없는 기능을 **직접 기획하고 타 부서에 발주해서 만들게 했다.**
이 축은 특정 지역이나 콘텐츠가 아니라, 반복된 **일하는 방식**이다.

## 반복된 패턴
```
내가 Story 담당(오너)  →  하위 Sub-Task를 부서별로 쪼개 생성  →  진행 관리
                          클라 / 서버 / 애니 / 이펙트 / 배경 / 배경원화 / 사운드 / TA
```

## 부수적으로 만든 작업 도구
기획만 한 게 아니라 **자기 작업을 편하게 만드는 툴도 발주**했다.
- 에디터에서 미끄러지기 경사도를 표시해주는 기능 (2022-10)
- 캐릭터의 현재 좌표 복사 및 붙여넣기 기능 (2022-10)
- 레벨 기믹을 위한 트리거 시스템 개발 (2022-10)
- 그리핀 던전 컨셉 설명용 쪽지 가젯 (2023-03) — 기획 의도 전달용 인게임 장치

## 왜 이 축이 중요한가
직함은 레벨 디자이너지만, 실제로 한 일의 상당 부분은 **시스템 기획과 크로스팀 조율**이다.
Jira 보고자 100건 + 과거담당 365건(내가 만들어 배분한 이슈 다수)이 그 증거다.
"내가 만든 레벨"만 세면 이 기여가 통째로 사라진다.
